Laptop Usage Analysis

About Project

This is a beginner-friendly Python project that analyzes daily laptop application usage using sample data.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

Features

- Demonstrates Python data types.
- Creates a DataFrame using Pandas.
- Calculates total, average and maximum usage hours.
- Displays data summary.
- Creates charts using Matplotlib.
- Exports data into an Excel file.

Libraries Installation

pip install pandas numpy matplotlib.

How to Run

python laptop_usage.py

Output

- Laptop Usage Summary
- Total and Average Hours
- Bar Charts
- Excel Report (Laptop_Usage.xlsx)
